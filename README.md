# Quantum Dot Games community guidelines

This repository provides shared community guidance and templates for repositories owned by Quantum Dot Games.

GitHub uses these files as defaults where an individual project has not supplied its own version. Project-specific instructions and licences take precedence.

- [Contributing](CONTRIBUTING.md): how to propose fixes, features, and other improvements.
- [Code of Conduct](CODE_OF_CONDUCT.md): expectations for constructive participation.
- [Security](SECURITY.md): how to report suspected vulnerabilities.
- [Support](SUPPORT.md): where to ask questions and report problems.

Funding, issue, and pull request templates are located in the [`.github`](.github) directory.

Individual projects may define additional technical or content-specific requirements, such as platform support, compatibility, performance, or third-party licensing. Check each project's README and other documentation before contributing.
