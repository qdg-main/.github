# Code of Conduct

We welcome respectful, constructive participation in Quantum Dot Games projects. Please discuss ideas and technical work in good faith, and be considerate of contributors with different experiences and perspectives.

Harassment, discriminatory abuse, threats, and deliberately disruptive conduct are not acceptable in project spaces. Criticism of ideas and code is welcome; personal attacks are not.

Maintainers may moderate discussions, remove inappropriate material, or restrict participation when necessary. If you need to report a conduct concern privately, contact the project maintainers using a contact method published by the relevant repository or organisation.
