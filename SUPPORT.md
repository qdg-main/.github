# Getting help

For help with a Quantum Dot Games project, start with its README and any project-specific documentation.

- **Bugs:** Open an issue in the affected repository. Include the version or environment and a description of the problem.
- **Feature ideas:** Use the repository's feature request issue template.
- **General questions:** Use GitHub Discussions if enabled for that project. Otherwise, check the project's documentation for an appropriate contact or discussion channel.
- **Security vulnerabilities:** Follow the [security policy](SECURITY.md); please do not post sensitive details in a public issue.

Support is provided as time permits. There is no guaranteed response time or commitment to implement requests.

GitHub Sponsors supports the ongoing development of these projects, but sponsorship does not imply priority support or influence over project decisions unless a specific arrangement explicitly says otherwise.
